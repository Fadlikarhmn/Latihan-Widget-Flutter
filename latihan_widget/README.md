# Kopi Senja

Aplikasi Flutter sederhana untuk menampilkan menu kedai kopi dan menambahkan
minuman ke pesanan.

## Tampilan

![Tampilan aplikasi Kopi Senja](screenshots/kopi_senja.png)

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```

Tekan **Tambah ke pesanan** untuk mencoba perubahan jumlah pesanan.
